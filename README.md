# isonoura-app

## 🚀 更新履歴 (Changelog)

### v1.9.0（最新）

- WAVE MAPを拡大・縮小できるように変更。2本指で拡大・縮小、1本指で移動、「戻す」ボタンで最初の表示に戻せます
- WAVE MAPの「戻す」「現在」ボタンを、すりガラス状で見やすく変更
- WAVE MAPの地点カードの見た目を新しくし、名前と波高、風向と風速の2行に整理
- WAVE MAPの地点カードが重ならないよう、置き場所を自動で調整
- WAVE MAPの陸地の線を、表示範囲に合わせて作り直し
- 波高データの取得範囲を広げ、7日分に対応
- データ取得に失敗したとき、待ってやり直すように変更
